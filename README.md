# Zinny's Beauty Studio – React + Tailwind + Framer Motion

```
npm install
npm run dev      # local preview
npm run build    # production build -> dist/
```

Everything lives in `src/App.jsx`. Edit WhatsApp numbers, services, gallery, reel and map address in the config block at the top.
Photos: `public/images/`. Favicons / app icons: `public/icons/`, `public/favicon.*`, `public/site.webmanifest`.
